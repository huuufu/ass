# 弹幕密度图生成工具
https://space.bilibili.com/9047380 4500万播放量经验,个人用的直播热度分析工具,现公开exe版本.
本工具为打包后的独立可执行文件（.exe），用于整合当前目录下所有文件名中包含符合特定 6 位数字格式的 ASS 文件，提取其中的弹幕数据后生成弹幕密度图。同时，点击图表时可以跳转播放对应的视频文件（支持 .mp4、.flv、.m4s 格式,需要提前输入potplayer路径）。
## 注意
脚本需要和xml文件置于同一个文件夹内,详细命名格式参考视频"https://www.bilibili.com/video/BV12CtveBEAn"
---

## 一、文件说明

打包后发布的包中包含以下文件：

- **弹幕图生成工具.exe**  
  程序主文件，双击运行即可启动 Web UI 服务，默认地址为 [http://127.0.0.1:8050](http://127.0.0.1:8050)。

- **config.ini**  
  程序配置文件，用于设置程序运行时需要的各项参数（目录路径、播放器路径、调试模式及关键词过滤等），详见下文说明。

---

## 二、使用说明

### 1. 准备工作

- **文件准备**  
  请将XML弹幕文件放置在同一目录下,XML文件应该为同一次直播的,可以跨天,从第一天晚上到第二天凌晨的都没有问题。  
例如![image](https://github.com/user-attachments/assets/088fb698-ecbf-4753-a39a-7ceeb16ec3a9)


- **配置文件设置**  
  打开与 exe 同目录下的 `config.ini` 文件，根据自己的实际情况修改相关参数（详见下文“配置文件参数说明”）。

### 2. 启动程序

- **双击运行**  
  双击 `弹幕图生成工具.exe` 文件后，程序会启动一个 Web 服务，并在默认浏览器中自动打开 [http://127.0.0.1:8050](http://127.0.0.1:8050)（如果 `is_debug_mode` 设置为 False）。

### 3. Web UI 界面功能

#### a. 图表操作
- **生成弹幕密度图**  
  程序会扫描当前目录（即 exe 所在目录）下符合条件的 ASS 文件，整合所有弹幕数据后生成弹幕密度图显示在界面上。  
  - 若弹幕条数不足 100 条，则页面下方会提示：“弹幕异常 请复制xml到本目录后,点击按钮"转换 XML 到 ASS"然后F5刷新页面”，并不会自动保存图表。
![image](https://github.com/user-attachments/assets/d3259129-3ab7-4511-99ff-b9afc4b43a0c)

- **鼠标在表内移动**  
  可以看到这个时间点的弹幕悬浮框.
![image](https://github.com/user-attachments/assets/a7fa83a1-6bae-4716-91f9-f0de6ef622a7)

- **点击图表**  
  点击图表中的任意位置，程序会根据点击位置自动计算所属 ASS 文件时间段，然后调用配置的视频播放器（PotPlayer）播放对应视频，并将视频文件的绝对路径复制到剪贴板。
![image](https://github.com/user-attachments/assets/43ae4446-9713-4266-8d62-bf4fab22a9e5)

#### b. 控制按钮

在 Web 界面顶部包含以下按钮（从左至右）：
- **保存当前页面**  
  保存当前生成的弹幕密度图为 HTML 文件，同时生成合并后的 ASS 文件。保存文件将放在配置文件中 `SAVE_DIR` 指定的目录下（文件名以目标日期命名）。
  - 如果当前版本的 HTML 内容与上次保存的完全一致，则提示“已经保存过本版本, 文件名：xxx”，防止重复保存。

- **撤回缩放**  
  如果你对图表进行了缩放操作，可点击此按钮撤回上一次的缩放设置，还原为上一个状态。

- **转换 XML 到 ASS**  
  扫描当前目录下所有符合条件的 XML 文件，并将它们转换为同名的 ASS 文件（转换生成的文件会和原 XML 文件在同一目录下）。
  
- **删除 XML**  
  删除当前目录下（不包括子目录）所有的 XML 文件。
  
- **删除 ASS**  
  删除当前目录下（不包括子目录）所有的 ASS 文件。

#### c. 自动保存功能
- 当弹幕数量（bullet_count）不少于 100 条时，系统会自动保存生成的图表文件（包括无竖线/注释版和带交互控件的完整版本以及合并后的 ASS 文件）。
- 如果弹幕数量不足，则自动保存区域会显示提示：“弹幕异常 请复制xml到本目录后,点击按钮"转换 XML 到 ASS"然后F5刷新页面”。

## 三、配置文件参数说明

配置文件 `config.ini` 用于设置程序运行相关参数，文件内容如下：

```ini
[Paths]
> ASS_FOLDER: 弹幕文件目录。程序会在该目录下扫描符合要求的 ASS 文件。
ASS_FOLDER = .

> SAVE_DIR: 保存自动及手动保存生成的 HTML 密度图与合并后的 ASS 文件的目录。
SAVE_DIR = ./Ass_Picture

> POTPLAYER_PATH: 指定视频播放器（如 PotPlayer）的完整路径。点击图表时将调用该播放器播放视频。
POTPLAYER_PATH = C:\PotPlayer\PotPlayerMini64.exe

> WORK_FOLDER: 可选配置。当在 ASS_FOLDER 中未找到对应视频文件时，程序会在该目录中查找视频文件。
WORK_FOLDER = F:\blrec\录播文件\26066074 (户晨风)

[Settings]
> is_debug_mode: 调试模式开关。
> - False: 程序启动后会自动打开浏览器（推荐用于正式使用）。
> - True: 不自动打开浏览器，适用于调试过程。
is_debug_mode = False

[Filter]
> exclude_keywords: 解析 ASS 文件时过滤掉的关键词，多个关键词之间用逗号分隔。
> 例如，如果某一行中包含广告、无效弹幕等关键词，则该行会被忽略。
exclude_keywords =
```

> **说明：**  
> - 请确保 exe 和 config.ini 位于同一目录。若 config.ini 不存在，程序会使用默认设置，并在控制台输出提示。

## 四、常见问题及注意事项

1. **配置文件读取问题**  
   请确保发布包中的 config.ini 与 exe 同目录。如果程序提示“配置文件 config.ini 不存在，使用默认设置”，请检查 config.ini 文件是否存在于 exe 同一目录内。

2. **视频播放问题**  
   - 视频文件支持 .mp4、.flv、.m4s 格式，且文件名中也必须包含符合要求的 6 位数字（仅包含即可,详细设置参考B站视频）。例如，文件名 `2024年10月01日223344.mp4` 中将提取 `223344` 作为基准时间。
   - 若当前目录内未找到对应的视频文件，则程序会在 WORK_FOLDER（若配置）中查找。

3. **XML 转 ASS**  
   只有XML文件,没有ASS文件,请点击“转换 XML 到 ASS”按钮，转换完成后刷新页面以重新生成弹幕密度图。

4. **保存图表**  
   如果弹幕数据不足 100 条(会视为根本没有数据)，页面会显示提示信息，不会进行自动保存；请确保弹幕文件完整后再进行保存操作。

5. **删除文件**  
   “删除 XML”与“删除 ASS”按钮仅针对程序所在目录（exe 同目录）下的文件，不会递归到子目录。请在使用前确认当前目录下文件无误。
